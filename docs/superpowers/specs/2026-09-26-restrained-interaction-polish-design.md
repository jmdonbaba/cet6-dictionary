# 克制型界面微交互设计

日期：2026-09-26

## 目标

在不改变信息层级和查词效率的前提下，让界面更有质感和交互反馈。整体气质保持清爽高级，弹性动画只作为短暂的入场反馈，不成为视觉主体。

## 视觉与动效

- 统一阴影：控件和卡片复用同一套浅色阴影层级；导出按钮不再使用独立的重阴影。
- 弹窗：打开时由 `scale(.98)` 和少量下移进入，带一次轻微、快速的弹性收束。
- 导出菜单：从右上锚点轻微缩放和下移进入，持续时间短于弹窗。
- 查询结果：内容首次出现时淡入并上移约 4px，不循环播放。
- Toast：淡入时同步上移少量距离，消失仍保持简洁。
- 按钮：按下时缩放至 `0.98`，松开立即恢复，不增加颜色闪烁。
- 卡片：仅鼠标设备悬停时使用统一的浅悬浮阴影，不改变位置。

## 边界

- 不增加渐变流光、粒子背景、持续漂浮或循环动画。
- 所有入场动效保持在约 160–280ms。
- `prefers-reduced-motion: reduce` 下关闭新增动画和缩放反馈。
- 触屏设备不启用悬停阴影，避免粘滞状态。

## 验证

结构测试检查统一阴影、关键入场动画、按钮按压反馈、悬停媒体查询与 reduced-motion 回退。完整测试集必须通过。

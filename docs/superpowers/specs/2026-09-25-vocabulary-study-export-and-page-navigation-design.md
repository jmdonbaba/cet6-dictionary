# 收藏词汇学习资料导出与页面快捷导航设计

日期：2026-09-25

## 目标

在现有单页 CET-6 查词工具中增加两项能力：

1. 在“词汇收藏”弹窗中，将全部收藏导出为适合阅读、背诵和打印的学习资料，支持 PDF、Word（`.docx`）、HTML 和 Markdown（`.md`）。
2. 在主页面右下角增加“回到顶部”和“前往底部”两个快捷按钮。

学习资料导出与页脚现有的 JSON“导出数据”保持独立。前者面向阅读和打印，不包含 API Key；后者继续用于数据备份与恢复。

## 已确认的产品决策

- 导出范围始终是全部收藏，不提供逐项勾选、全选或仅导出搜索结果。
- 收藏夹现有搜索继续只用于查找和浏览收藏，不影响导出范围。
- 收藏夹标题栏增加一个简洁的“导出”按钮；点击后弹出格式菜单，不显示“全部”或“导出全部……”等说明文案。
- 菜单依次提供 PDF、Word、HTML、Markdown 四种格式。
- 采用“背诵讲义”版式：信息完整，适合打印和手写复习。
- 每个单词最多展示现有收藏数据中的 3 组英文例句及中文翻译；不足 3 组时按实际数量输出，不生成虚构内容。
- PDF 直接下载，不调用浏览器打印窗口。
- PDF 以视觉效果为优先，可使用高分辨率图像式页面；Word、HTML 和 Markdown 保留可编辑文本。
- 主页面上下跳转按钮固定在右下角竖排显示，页面无可滚动内容时隐藏，到达边界时禁用对应按钮。

## 界面设计

### 收藏夹导出入口

“词汇收藏”弹窗标题栏从左到右排列：标题及收藏数量、“导出”按钮、关闭按钮。“导出”按钮使用项目现有主色，尺寸与关闭按钮协调，不挤压标题。

点击“导出”后，在按钮附近显示轻量菜单：

- PDF · 精美打印版
- Word · 可编辑文档
- HTML · 浏览器文档
- Markdown · 纯文本

菜单点击外部、按 Escape、关闭弹窗或开始导出后收起。收藏为空时禁用“导出”按钮，并保留现有空状态提示。

生成期间，按钮进入忙碌状态并显示“正在生成…”，防止重复点击。生成成功后浏览器直接下载文件并显示轻量提示；失败则恢复按钮并显示可理解的错误提示。

### 背诵讲义版式

文档使用 A4 纵向页面和清晰的单栏结构。首页包含简洁标题、生成日期和总词数，不加入与学习无关的装饰。

每个单词作为一个完整学习单元，包含：

- 单词、音标、词性；
- “已掌握”空白勾选框；
- 核心释义或完整 definitions；
- 词形变化与同根派生；
- 最多 3 组英文例句及中文翻译；
- 一块带横线的复习笔记区。

分页优先避免把单词标题与释义拆开，也避免将单条中英例句拆到两页。单词内容超过剩余空间时整体移至下一页；单个学习单元本身超过一页时才允许在例句或笔记区之间自然分页。

印刷配色以深灰文字、靛蓝标题和浅灰分隔为主；即使黑白打印，也能依靠字号、字重和边框维持层级。

### 主页面上下跳转按钮

两个圆形按钮固定在主页面右下角，向上按钮在上、向下按钮在下。它们使用统一阴影、主色和清晰箭头，并带有中文 `aria-label` 与 `title`。

- 点击后使用平滑滚动到文档顶部或底部。
- 滚动到顶部时禁用向上按钮；滚动到底部时禁用向下按钮。
- 页面高度没有超过视口时整组隐藏。
- 手机端使用安全区间距，避免贴住屏幕边缘；按钮不能覆盖主要输入控件或页脚链接。
- 弹窗打开时隐藏这组按钮，避免与弹窗交互层重叠。
- 尊重 `prefers-reduced-motion`：用户偏好减少动态时改为即时跳转。

## 数据与生成流程

所有格式共用一个纯数据转换层，将 `getVFavs()` 返回的收藏记录规范化为导出模型：

- 缺失字段统一为空字符串或空数组；
- `definitions` 优先作为结构化释义，缺失时回退到 `meaning`；
- `examples` 兼容字符串和 `{ en, cn }` 两种历史形态，只截取前 3 项；
- 词形字段保留用户当前收藏内容；
- 导出顺序与收藏夹当前保存顺序一致，包括置顶和手动排序结果；
- 对所有动态文本进行格式对应的转义，防止收藏内容破坏 HTML、Markdown 或文档结构。

导出流程：

1. 用户选择格式。
2. 读取全部收藏并建立一次不可变的导出快照。
3. 使用对应渲染器生成文件。
4. 通过 Blob 和临时下载链接触发浏览器下载。
5. 释放临时 URL 和用于渲染的离屏节点。

文件名统一包含日期时间，例如：

- `cet6-vocabulary-20260925-143000.pdf`
- `cet6-vocabulary-20260925-143000.docx`
- `cet6-vocabulary-20260925-143000.html`
- `cet6-vocabulary-20260925-143000.md`

## 格式实现策略

### PDF

用隔离的离屏讲义 DOM 渲染 A4 页面，再以高分辨率画布生成多页 PDF。PDF 渲染依赖以固定版本的本地浏览器包随项目发布，避免运行时 CDN 失效。渲染节点使用专用样式，不复用收藏弹窗尺寸，确保桌面端和手机端下载得到一致结果。

长文档分批让出主线程，并显示忙碌状态。生成完成后直接下载，不调用 `window.print()`。

### Word

通过固定版本的本地浏览器端 DOCX 生成库创建真实 `.docx` 文件。标题、段落、列表、表格或边框均使用 Word 原生结构，保证文字可编辑，并控制单词学习单元的分页行为。

### HTML

生成完整、可独立打开的 UTF-8 HTML 文件，内联讲义样式和打印媒体规则，不依赖项目页面资源。用户可直接在浏览器阅读、另存或上传到支持 HTML 导入的文档工具。

### Markdown

使用稳定的标题、释义列表、例句编号、任务复选框和笔记分隔线。对反斜杠、标题符号、列表符号、竖线等字符进行转义，确保普通 Markdown 阅读器中结构稳定。

## 代码组织

项目继续保持单页、无构建步骤的使用方式：

- `index.html`：新增导出入口、菜单、快捷导航按钮、样式和应用逻辑。
- `vendor/`：存放固定版本的 PDF 与 DOCX 浏览器端依赖及许可文件。
- `tests/`：增加基于 Node 内置测试器的结构和行为测试。

应用逻辑拆分为命名清晰的小函数：导出模型构建、文件名生成、各格式渲染、Blob 下载、菜单状态、导出忙碌状态、快捷导航状态。现有 JSON 数据备份函数不复用学习资料导出入口，避免概念混淆。

## 容错与边界情况

- 收藏为空：禁用导出入口。
- 历史收藏缺失音标、词性、词形、中文翻译或例句：跳过对应空块，版面不保留大面积空白。
- 特殊字符、emoji、中文标点：HTML 和 Markdown 正确转义；PDF 与 DOCX 使用支持中英文的字体回退栈。
- 收藏数量较多：导出期间防止重复触发，并保持页面可见的进度反馈。
- 依赖加载失败或浏览器不支持所需 API：提示具体格式生成失败，不影响其他格式和现有收藏数据。
- 导出过程不修改收藏、不读取或写入 API Key。

## 可访问性与响应式要求

- 导出按钮、菜单项和快捷导航均可通过键盘操作。
- 菜单使用合适的 ARIA 展开状态，Escape 可关闭，并在关闭后将焦点归还“导出”按钮。
- 忙碌状态通过按钮文本和 `aria-busy` 同时表达。
- 快捷导航按钮至少提供约 44×44 像素的触控区域。
- 窄屏标题栏允许合理换行，但导出按钮和关闭按钮不溢出弹窗。

## 验证方案

自动化测试覆盖：

- 收藏为空和非空时导出按钮状态；
- 导出菜单的打开、关闭和格式项文案；
- 导出模型对历史字段形态、空字段和 3 条例句上限的处理；
- HTML、Markdown 的转义和核心内容结构；
- PDF 生成不调用打印窗口；
- 学习资料导出不包含 API Key；
- 上下跳转按钮的边界状态、无滚动时隐藏、弹窗打开时隐藏；
- 手机端 CSS 不产生横向溢出。

人工验收覆盖桌面端与常见手机宽度，使用包含中文、长单词、长释义、3 条双语例句和缺失字段的收藏样本，分别下载四种格式并检查：

- PDF 页边距、分页、清晰度与直接下载；
- Word 可编辑性与中英文显示；
- HTML 独立打开和打印样式；
- Markdown 在常见阅读器中的结构；
- 主页面快捷按钮不遮挡操作元素。

## 非目标

- 不提供单词逐项勾选或仅导出搜索结果。
- 不提供打印窗口或站内打印按钮。
- 不修改现有 JSON 数据导出、导入及 API Key 备份行为。
- 不在本次功能中增加云端同步、分享链接或自定义模板编辑器。

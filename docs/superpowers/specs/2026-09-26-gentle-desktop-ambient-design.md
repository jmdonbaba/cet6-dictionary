# 温柔桌面环境光与侧边导航设计

日期：2026-09-26

## 目标

在不影响查词与阅读的前提下，为桌面端增加温柔的环境互动，并让上下跳转按钮与主单词卡片形成更明确的空间关系。

## 侧边导航

- 仅在宽度大于 1000px 的桌面视口显示。
- 固定在主内容列右侧约 16px、视口垂直中线处，视觉上位于单词卡片外侧正中。
- 窄屏与手机端完全隐藏，不覆盖卡片内容。
- 保留页面不可滚动时隐藏、到达顶部或底部时禁用、弹窗打开时隐藏的既有逻辑。
- 使用内联 SVG 圆角线条箭头，统一线宽、圆角端点和连接点；按钮仍保留明确的中文无障碍标签。

## 温柔背景互动

- 灰色背景叠加低透明度的薰衣草紫与暖白静态光斑。
- 精确鼠标设备上增加约 280px 的柔和追光区域，中心随指针移动，边缘无明显圆环。
- 指针移动使用 `requestAnimationFrame` 合并更新，避免每次事件都触发样式写入。
- 指针离开窗口时追光缓慢淡出。
- `prefers-reduced-motion: reduce` 下不注册追踪逻辑，只保留静态环境光。

## 边界

- 不增加粒子、波纹、卡片倾斜、强光晕或循环漂浮动画。
- 背景层不接收指针事件，不遮挡正文、弹窗、Toast 或快捷按钮。
- 不修改查词、收藏、导出和滚动行为。

## 验证

结构测试覆盖桌面定位、手机隐藏、SVG 箭头、静态环境光、帧同步鼠标追光、离开淡出和减少动态效果回退；完整测试集必须通过。

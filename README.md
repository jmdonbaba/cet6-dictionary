# CET-6 查词助手

- 结合我自身六级搜词需求，适合六级宝宝体质的搜词器。
- 独立的 CET-6 英语查词工具，从 [Cet6Writing](https://github.com/jmdonbaba/Cet6Writing) 项目中剥离，单独优化，之后再并入。

## 功能

- **AI 查词**：输入单词或短语，调用 DeepSeek API 返回释义、英式与美式音标、词性、变形、学术例句；旧收藏在下次查询时补全双音标，收藏、保存页面和导出均保留两套音标
- **怎么记**：桌面左侧公共工具区生成拆分记忆和词块来源，主卡片保持页面居中；生成不自动收藏，已收藏词需手动点击“收藏”后才补充记法，此时提示“记法已补充到单词收藏”；未收藏词在记法卡片原位自动查词，成功后单词与记法一起收藏并提示“单词与记法已一起收藏”，失败保留记法供重试；记法面的“取消收藏”只移除记法、保留单词收藏（再点收藏提示“记法已补充到单词收藏”），要连同单词一起取消请到“单词释义”面点“取消收藏”；翻面时收藏按钮提前就位，不会翻完才出现
- **拆分记忆**：记法只保留“词块（中文含义） + 词块（中文含义） → 组合含义 → 单词释义”这条公式和每个词块的来源，不再额外生成“这样联想 / 记住这一点”等复述段落；来源行如实说明词块是词根、前缀、后缀，还是联想到某个英文单词（例如 plaus ← 词根：拍手、鼓掌，与 applause 同源），纯联想会明确写出，不把联想当词源；收藏详情和 HTML/Markdown 讲义保留相同格式，旧的联想/提示段落仍可读取
- **释义与记法翻面**：同一张单词卡片可通过“单词释义 / 怎么记”按钮绕中心竖轴翻转，翻转采用平面转动，两面高度差在翻面过程中平滑过渡，卡片下端和收藏按钮都不会卡顿或延后出现；优先复用当前卡片、其他卡片或收藏中的释义，没有时才查询；两面的内容和当前显示面参与刷新及保存页面恢复，系统减少动态效果时直接切换
- **卡片内生成记法**：单词信息行最右侧可直接点击“生成记法”，按当前结果单词生成，在原卡片翻面展示，不新增卡片或自动收藏；生成失败保留原释义，可再次点击重试
- **词语对比**：输入两个词，生成核心区别、使用场景、搭配和例句；手动收藏到同一收藏入口的“词语对比”页签，支持搜索、置顶、删除、打开卡片和讲义导出；交换两个词的顺序不会重复收藏
- **手机工具切换**：公共工具区通过“怎么记 / 词语对比”页签点击或左右滑动切换，结果卡片继续上下阅读；兼容键盘操作和系统减少动态效果设置
- **变形还原**：自动识别过去式、现在分词等变形，显示原形结果
- **多窗口查词**：支持 +/− 按钮添加/删除多个查词窗口，可同时查询多个单词
- **词汇收藏**：收藏感兴趣的词汇，支持置顶、查看详情、删除
- **记法与对比备份**：记法跟随单词收藏及 HTML/Markdown 讲义导出；对比使用独立本地存储，完整数据备份包含两类收藏；旧备份不清空对比收藏，新结果卡片也参与刷新恢复与保存页面
- **定位未收藏卡片**：点击卡片右侧下方的方形双星按钮（上实心、下空心），跳到页面中第一个尚未收藏的查询结果
- **轻量 Q 弹交互**：按钮按压回弹、模式滑块、卡片入场和弹层展开采用统一的轻弹效果，支持系统减少动态效果设置
- **界面设置与主题**：右上角齿轮打开设置面板，可切换「传统界面 / 玻璃质感（开发中）」，并从「极简 / 极光 / 蜜桃 / 深空 / 水波」中选择背景主题。两套界面分别记住各自的主题：传统界面默认「极简」（最初的样子），玻璃质感默认「极光」。选择保存在本地浏览器，刷新或下次打开自动恢复；切换即时生效，支持键盘操作、Esc 关闭与点击遮罩关闭
- **玻璃交互**：鼠标悬停会在当前玻璃表面产生跟随指针的小范围凹陷，真实改变附近的背景采样，并通过上左内壁暗部、下右弧面反光与轻微底部遮蔽建立明确的凹陷深度；即使背景纯色也能辨认；点击出现有衰减的果冻回弹。静止时仍保持原有“边缘鼓、中间平”的材质；交互只改变光学层与装饰层，文字清晰、点击区域固定。支持卡片、按钮和弹窗；鼠标停住、移出或回弹结束后自动停止更新，切换界面/关闭效果/失焦会清理凹陷，减少动态效果或减少透明度时停用此交互。
- **玻璃按钮**：所有按钮使用更低遮色的透明底与柔和反光，折射强度通过连续平滑曲线从外缘向中心逐渐减弱，过渡带扩宽，中心核心保持平坦、不放大；位移变化受限以避免内部折回分界，圆角采用保持方向的二维坐标场。小按钮通过曲面强度归一化（最高 2.6 倍）获得相对更明显的边缘弯折；这不是随尺寸改变材质折射率。主界面按钮复用共享 GPU 画布，先复制卡片合成背景一次，再按各按钮的小矩形裁切绘制，不增加全屏透镜循环。弹窗与原生降级使用独立背景伪元素，只扭曲装饰背景，文字/图标始终清晰；动态按钮和刚展开的菜单会自动更新。收藏/删除色彩、禁用与键盘焦点保持可辨认，传统界面保持原样。
- **玻璃质感界面（开发中）**：卡片采用无连续描边的透明玻璃，内容与玻璃层分离（文字不会被折射滤镜扭曲），通过更宽的透镜折射带、中心轻微放大、真实 RGB 采样色散、固定局部反光和柔和投影表现厚度；不同背景主题共用同一套 UI、材质与交互，只替换壁纸，不为深空等主题单独修改卡片和控件样式；背景可选极光色域、暖色日落、暗色深空或程序生成的浅水焦散（水波）；玻璃模式的背景保持静止，避免每帧重算所有玻璃表面，Q 弹反馈保留在小控件上。系统开启“减少动态效果”时停用动态反馈；不支持背景模糊或开启“减少透明度”时自动降级为清晰卡片，可读性优先
- **收藏打开卡片**：展开收藏后点击“在卡片中打开”，保留收藏夹并定位背景卡片；已打开的单词直接定位
- **刷新恢复卡片**：自动保存卡片顺序、输入、查询模式和结果，在当前标签页刷新时恢复，无需重新查词
- **多标签页恢复**：每个标签页刷新时恢复自己的卡片，新打开的页面保持空白；关闭浏览器或重启电脑前，请使用“保存页面”保留需要的内容
- **保存与恢复页面**：无需命名或下载文件，保存后按时间、卡片数量和单词预览选择记录；覆盖已有内容时先确认，恢复后仍保留记录，可重复恢复，只有手动删除才移除；重启电脑后可在“恢复页面”中找回（需使用同一浏览器、同一页面地址并保留网站本地数据）
- **保存检查与备份**：查询中会提示等待完成，保存页面使用 IndexedDB 严格持久化事务，等待事务提交并校验后才提示成功，避免浏览器被强制结束时丢失刚保存的记录；旧版页面记录自动迁移，并在浏览器支持时申请持久存储保护；底部“导出数据”包含保存页面、收藏和 API Key，“导入数据”可找回页面记录，重复导入不会重复添加，覆盖收藏也会保留已有页面记录
- **共享收藏**：与原 Cet6Writing 项目共享 `localStorage` 中的词汇收藏数据

## 技术栈

- 纯前端 HTML/CSS/JS（无依赖）
- DeepSeek API（deepseek-flash）
- IndexedDB 严格持久化事务保存页面记录；localStorage 保存 API Key 和收藏；sessionStorage 保存当前标签页的刷新快照
- 界面外观（`appearance.css` / `appearance.js`）：界面（`cet6_interface_style`）与背景主题（`cet6_theme_classic` / `cet6_theme_glass`）双维度设置；玻璃质感用低雾度 `backdrop-filter` + SVG 背景折射 + 局部反光实现，不引入 React 或第三方运行时依赖；极光、蜜桃和深空增加共用光带轮廓（`assets/glass-ribbons.svg`，同一 SVG 内嵌为 CSS mask，支持直接打开本地 HTML）；水波背景由 `tools/generate-water-caustics.py` 程序生成的原创图 `assets/water-caustics.webp` 提供，不依赖第三方素材
- 液态折射（`glass-renderer.js` / `glass-refraction.js`）：支持的桌面 Chromium 优先用一张共享 WebGL 画布，一次绘制主题壁纸和最多 16 个可见卡片透镜，中心放大与边缘 RGB 色散共用同一个着色器；只在滚动、尺寸、主题或内容变化时重绘，空闲时不循环绘制。折射采样来自壁纸，不捕获或扭曲 DOM 文字。弹窗位于模糊遮罩上方，保留弹窗自身的原生背景捕获和单次 SVG 位移，避免把遮罩下方的透镜错误用于弹窗。
- 兼容与性能：无 WebGL 或显卡上下文丢失时自动退回单次 SVG 位移；位移图从 512² 降到 256²，避免重复写入未变化的滤镜参数。小屏（≤720px）、低性能设备及不支持的浏览器使用透明磨砂降级；支持减少动态效果与减少透明度偏好。各主题共用同一套材质/折射逻辑。
- 本地纹理：在线页面直接复用 `assets/water-caustics.webp`；直接打开本地 HTML 时，按需加载同一图片的内嵌版本 `assets/water-caustics-data.js`，避免 WebGL 跨源限制，不增加普通页面的阻塞加载。修改水波图片后运行 `python tools/generate-water-texture.py` 重新生成。

## 与Cet6Writing的关系

- 共享 `cet6_api_key` — API Key 两个项目只需配置一次
- 共享 `cet6_vocab_favorites` — 任一项目中收藏/删除的词汇会自动同步
- 不包含作文生成功能，纯查词+收藏

## 使用方式

- **在线使用**：https://jmdonbaba.github.io/cet6-dictionary/
- **本地使用**：直接用浏览器打开 `index.html` 即可使用。

保存页面属于当前浏览器的网站数据。无痕模式、切换浏览器配置、清除网站数据或 Edge 的关闭时清理设置仍可能导致记录不可用，持久存储申请不能阻止用户主动清理。重要页面请使用“导出数据”另存备份；旧版备份不含页面记录。

## 验证

- `node --test tests/*.test.js`：运行无依赖的自动化测试（含 `tests/appearance.test.js` 对设置入口、界面/主题持久化、玻璃分层与降级规则的结构断言）。
- 安装 Playwright 后，运行 `node tests/study-tools.browser.js` 验证双面翻转与恢复、收藏/取消收藏、原位查词、查询/存储失败重试、备份与讲义导出、页面恢复、手机真实触摸滑动及 320–1920px 居中布局。使用隔离浏览器和模拟 API，不读取日常浏览器数据、不消耗真实 API 配额；支持 `PLAYWRIGHT_MODULE` 和 `EDGE_EXECUTABLE`。
- 安装 Playwright 后，运行 `node tests/liquid-glass.browser.js` 验证默认主题实际折射像素差、不同尺寸/动态卡片的透镜更新、主题只替换背景、无卡片描边、清晰文字、手机降级和资源释放，截图输出到 `.gstack/liquid-glass/`；支持 `PLAYWRIGHT_MODULE` 和 `EDGE_EXECUTABLE`。
- `node --test tests/glass-optics.test.js`：验证渐变曲线两端平滑、不同尺寸/强度下采样单调、圆角二维采样不倒转；GPU 与原生位移共用 `glass-optics.js` 的曲线策略。
- `node tests/glass-interaction.browser.js`：验证悬停局部像素变化、纯色背景上的凹面明暗方向、按弹簧相位采样的点击回弹、固定点击区域、文字清晰度、停止绘制、禁用后无残留凹陷、弹窗原生压力场释放及减少动态效果。
- `node tests/button-refraction.browser.js`：直接读取渲染像素，验证按钮中央零变化、边缘实际弯折、弹窗与新展开菜单的按钮折射及文字清晰度。
- `node tests/glass-performance.browser.js`：验证空闲时不持续绘制、滚动/鼠标移动不重复重建 SVG、减少透明度降级和 WebGL 上下文丢失后的原生恢复；输出极简/玻璃的帧间隔对照。`GLASS_FORCE_FALLBACK=1 node tests/liquid-glass.browser.js` 可强制检查无 WebGL 路径（PowerShell 用 `$env:GLASS_FORCE_FALLBACK='1'`）。
- `node tools/benchmark-glass.cjs`：隔离浏览器创建 10 张卡片，对比极简/玻璃在空闲、鼠标移动、连续滚动下的帧间隔、慢帧数和主线程耗时，结果写入 `.gstack/glass-perf/latest.json`。2026-11-01 的同机 Edge 1440×900 对照中，旧玻璃滚动 P95 约 139ms，新版约 7ms，与极简约 7ms 接近；这属于该测试环境的帧调度结果，不代表所有设备或浏览器的固定帧率。
- 安装 Playwright 后，运行 `node tests/appearance.browser.js` 验证右上角设置入口、界面与主题切换、刷新持久化、键盘操作、深空主题文字对比、无横向滚动与减少动态效果降级；同样支持 `PLAYWRIGHT_MODULE` 和 `EDGE_EXECUTABLE`。
- Windows 上安装 Playwright 后，可运行 `node tests/saved-page-durability.browser.js`，验证 Edge 被强制结束后的保存记录、旧数据迁移、删除防恢复和多标签页同步。测试使用独立临时浏览器配置，不操作日常使用的 Edge；可通过 `PLAYWRIGHT_MODULE` 和 `EDGE_EXECUTABLE` 指定已有的运行环境。

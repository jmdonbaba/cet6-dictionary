# CET-6 查词助手

- 结合我自身六级搜词需求，适合六级宝宝体质的搜词器。
- 独立的 CET-6 英语查词工具，从 [Cet6Writing](https://github.com/jmdonbaba/Cet6Writing) 项目中剥离，单独优化，之后再并入。

## 功能

- **AI 查词**：输入单词或短语，调用 DeepSeek API 返回释义、英式与美式音标、词性、变形、学术例句；旧收藏在下次查询时补全双音标，收藏、保存页面和导出均保留两套音标
- **怎么记**：桌面左侧公共工具区生成拆分记忆和词块来源，主卡片保持页面居中；生成不自动收藏，已收藏词需手动点击“收藏”后才补充记法，此时提示“记法已补充到单词收藏”；未收藏词在记法卡片原位自动查词，成功后单词与记法一起收藏并提示“单词与记法已一起收藏”，失败保留记法供重试；记法面的“取消收藏”只移除记法、保留单词收藏（再点收藏提示“记法已补充到单词收藏”），要连同单词一起取消请到“单词释义”面点“取消收藏”；翻面时收藏按钮提前就位，不会翻完才出现
- **拆分记忆**：记法只保留“词块（中文含义） + 词块（中文含义） → 组合含义 → 单词释义”这条公式和每个词块的来源，不再额外生成“这样联想 / 记住这一点”等复述段落；来源行如实说明词块是词根、前缀、后缀，还是联想到某个英文单词（例如 plaus ← 词根：拍手、鼓掌，与 applause 同源），纯联想会明确写出，不把联想当词源；收藏详情和 HTML/Markdown 讲义保留相同格式，旧的联想/提示段落仍可读取
- **词组记忆**：先讲每个完整单词的常见基本义，再说明它在当前搭配中的意思或作用，最后串起词组整体意思（例如 resolve 先解释“解决；作出决定”，再引出 resolve to 的“决心做某事”）；不把词组里的单词继续拆成词根、前缀或后缀。约定俗成的整体义无法由字面严格推导时如实说明，卡片、收藏和讲义统一显示“词语解释”，生成时校验各部分与原词组单词逐一对应。
- **释义与记法翻面**：同一张单词卡片可通过“单词释义 / 怎么记”按钮绕中心竖轴翻转，保留平面转动。高度与翻转共用渐入渐出缓动，按两面高度差调整时长并一起结束；换面后的首帧保持侧立，避免完整卡片闪现。收藏弹窗高度也使用同一段动画，越过高度上限时不会突然启停，底部按钮跟随卡片下沿移动。优先复用当前卡片、其他卡片或收藏中的释义，没有时才查询；两面的内容和当前显示面参与刷新及保存页面恢复，系统减少动态效果时直接切换。
- **卡片内生成记法**：单词信息行最右侧可直接点击“生成记法”，按当前结果单词生成，在原卡片翻面展示，不新增卡片或自动收藏；生成失败保留原释义，可再次点击重试
- **词语对比**：输入两个词，生成核心区别、使用场景、搭配和例句；手动收藏到同一收藏入口的“词语对比”页签，支持搜索、置顶、删除、打开卡片和讲义导出；交换两个词的顺序不会重复收藏
- **手机工具切换**：公共工具区通过“怎么记 / 词语对比”页签点击或左右滑动切换，结果卡片继续上下阅读；兼容键盘操作和系统减少动态效果设置
- **变形还原**：自动识别过去式、现在分词等变形，显示原形结果
- **多窗口查词**：支持 +/− 按钮添加/删除多个查词窗口，可同时查询多个单词
- **收藏**：单词、词语对比、例句讲解分为三个页签，均支持手动收藏、搜索、置顶、打开和删除；收藏总数包含三类内容。
- **单词与记法收藏关系**：释义面的按钮只收藏单词，记法面的按钮收藏当前记法并确保单词同时收藏。取消记法收藏保留单词；取消或删除单词会一并移除其记法收藏。两面分别显示自己的收藏状态，未保存或已取消收藏的记法仍留在卡片中，重新收藏单词不会自动把它带回收藏。
- **收藏状态与版本**：收藏按钮对应当前展示的内容；对比、例句重新生成后需手动收藏新版本，更新保留原条目的标识、置顶和位置。打开收藏时复用内容相同的卡片，当前有未保存版本时另开收藏的实际内容，保留未保存结果。
- **收藏写入检查**：写入并校验成功后才切换收藏状态；读取异常、存储不足或异常导入不会清空已有收藏，拖拽排序也在读取失败时停止。多标签页会同步刷新实际收藏列表，翻面尚未完成时收藏按钮保持不可点击。
- **统一单词输入**：查词、怎么记和词语对比共用标准化方法，统一全角字符、空白和小写；例句及疑问保留原有大小写和标点。
- **例句讲解**：左侧输入例句及可选疑问，生成翻译、句子结构和语法要点；有疑问时另行直接解答。生成不自动收藏，相同例句的不同疑问可以分别保存。支持重新生成、失败重试、页面恢复、HTML/Markdown 讲义与完整备份；旧备份导入不会清空新类型收藏。
- **记法与对比备份**：记法跟随单词收藏及 HTML/Markdown 讲义导出；对比使用独立本地存储，完整数据备份包含两类收藏；旧备份不清空对比收藏，新结果卡片也参与刷新恢复与保存页面
- **定位未收藏卡片**：点击卡片右侧下方的方形双星按钮（上实心、下空心），跳到页面中第一个尚未收藏的查询结果
- **收藏夹快捷入口**：双星按钮右侧提供紧凑的“收藏夹”入口，不显示数量，直接打开全部收藏；滚动时两个入口之间的材质会拉伸、粘合和回弹，标签保持清晰。持续滚动时衔接跟随按钮当前位置，快速反向时从当前形状接续。手机端保持并排且不超出安全区域，减少动态效果时直接切换。
- **轻量 Q 弹交互**：按钮按压回弹、模式滑块、卡片入场和弹层展开采用统一的轻弹效果，支持系统减少动态效果设置
- **界面设置与主题**：右上角齿轮打开设置面板，可切换「传统界面 / 玻璃质感（开发中）」，并从「极简 / 水波 / 极光 / 蜜桃 / 深空」中选择背景主题。两套界面分别记住各自的主题：传统界面默认「极简」（最初的样子），玻璃质感默认「水波」。选择保存在本地浏览器，刷新或下次打开自动恢复；切换即时生效，支持键盘操作、Esc 关闭与点击遮罩关闭
- **玻璃交互**：鼠标悬停会在当前玻璃表面产生跟随指针的小范围折射变化，点击出现有衰减的果冻回弹；不额外绘制凹陷明暗或圆形阴影。静止时仍保持“边缘鼓、中间平”的材质；交互只改变光学层与装饰层，文字清晰、点击区域固定。支持卡片、内部分层、按钮和弹窗；鼠标停住、移出或回弹结束后自动停止更新，切换界面/关闭效果/失焦会清理交互，减少动态效果或减少透明度时停用此交互。
- **整体折射板**：释义、词形和例句共用一块完整结果板，不再逐段设置透镜，也不叠加白色底色或例句边线；“怎么记”面直接使用外层卡片，不再叠加中间玻璃，翻回释义后恢复正常结果板。共享 GPU 读取外层已经合成的背景，并裁切到自身及祖先的圆角范围；滚动条、高分屏和缩放下使用画布实际边界定位，避免按钮旁多出偏移圆、卡片外多出折射条。按钮保留独立透镜，弹窗与原生降级也使用相同的分层规则。
- **工具与收藏详情分块**：左侧“怎么记 / 词语对比 / 例句讲解”为三张独立卡片，以留白代替分隔线；平板并排、手机支持三页切换。收藏详情默认显示释义、词形和例句；只有保存了记法的词条才显示“怎么记”翻转按钮，两面各使用一整块玻璃，不再叠加内容板或分隔线。重新打开收藏时回到释义面，查看不请求接口或修改收藏。
- **玻璃按钮与输入框**：所有按钮、滑动胶囊和输入框使用透明底与轻微反光，收藏、删除等状态只保留少量语义染色；原形/原词的文字保持同色，仅滑动胶囊表示选中。折射强度在外缘快速升高，通过平方后的连续平滑曲线向内衰减，扩大大板过渡范围以增强厚边，中心核心保持平坦、不放大；位移变化受限以避免内部折回分界，圆角采用保持方向的二维坐标场。小按钮通过曲面强度归一化（最高 2.6 倍）获得相对更明显的边缘弯折；这不是随尺寸改变材质折射率。按钮、胶囊和输入框复用共享 GPU 画布，原形/原词与收藏页签的选项本身不各自生成透镜。所有搜索框聚焦时整框折射渐强，失焦平滑恢复，保持同样的透明底色和清晰文字。动态按钮、滑动胶囊和刚展开的菜单会自动更新，传统界面保持原样。
- **收藏页签与搜索**：收藏的“单词 / 词语对比”复用“原形 / 原词”的可拖动胶囊，使用平移与原有弹簧缓动，支持键盘切换及窗口缩放。弹窗按两边内容统一取较高的高度，内容少时收紧，最多占视口高度的 80%；两个分区保留排版、各自滚动，切换只改变可见性，不重读收藏、不重建列表，也不为已有 GPU 光学层生成额外 SVG 滤镜。其他控件结束过渡不会中断胶囊的折射更新；菜单光学仍裁切在分区内。两处搜索候选均在自身范围模糊背景，避免与底下的单词重叠；卡片内容不整块虚化。玻璃界面的滚动条使用透明轨道和细的半透明滑块，手机工具横向滑动条继续隐藏。
- **玻璃质感界面（开发中）**：卡片采用无连续描边的透明玻璃，内容与玻璃层分离（文字不会被折射滤镜扭曲），通过渐变透镜折射带、平坦中心、真实 RGB 采样色散、固定局部反光和柔和投影表现厚度；不同背景主题共用同一套 UI、材质与交互，只替换壁纸，不为深空等主题单独修改卡片和控件样式；背景可选程序生成的浅水焦散（水波，默认）、极简、极光、蜜桃和深空。水波随屏幕刷新流动，极光、蜜桃和深空的光带缓慢漂移，极简带有一层很淡的游光。小控件提供轻弹反馈。系统开启“减少动态效果”时停用动态反馈；不支持背景模糊或开启“减少透明度”时自动降级为清晰卡片，可读性优先
- **收藏打开卡片**：展开收藏后点击“在卡片中打开”，保留收藏夹并定位背景卡片；已打开的单词直接定位
- **刷新恢复卡片**：自动保存卡片顺序、输入、查询模式和结果，在当前标签页刷新时恢复，无需重新查词
- **多标签页恢复**：每个标签页刷新时恢复自己的卡片，新打开的页面保持空白；关闭浏览器或重启电脑前，请使用“保存页面”保留需要的内容
- **保存与恢复页面**：无需命名或下载文件，保存后按时间、卡片数量和单词预览选择记录；覆盖已有内容时先确认，恢复后仍保留记录，可重复恢复，只有手动删除才移除；重启电脑后可在“恢复页面”中找回（需使用同一浏览器、同一页面地址并保留网站本地数据）
- **保存检查与备份**：查询中会提示等待完成，保存页面使用 IndexedDB 严格持久化事务，等待事务提交并校验后才提示成功，避免浏览器被强制结束时丢失刚保存的记录；旧版页面记录自动迁移，并在浏览器支持时申请持久存储保护；底部“导出数据”包含保存页面、收藏和 API Key，“导入数据”可找回页面记录，重复导入不会重复添加，覆盖收藏也会保留已有页面记录
- **共享收藏**：与原 Cet6Writing 项目共享 `localStorage` 中的词汇收藏数据

## 技术栈

- 纯前端 HTML/CSS/JS（无依赖）
- DeepSeek API（deepseek-flash）
- IndexedDB 严格持久化事务保存页面记录；localStorage 保存 API Key 和收藏；sessionStorage 保存当前标签页的刷新快照
- 界面外观（`appearance.css` / `appearance.js`）：界面（`cet6_interface_style`）与背景主题（`cet6_theme_classic` / `cet6_theme_glass`）双维度设置；玻璃质感用低雾度 `backdrop-filter` + SVG 背景折射 + 局部反光实现，不引入 React 或第三方运行时依赖；极光、蜜桃和深空增加共用光带轮廓（`assets/glass-ribbons.svg`，同一 SVG 内嵌为 CSS mask，支持直接打开本地 HTML）；水波背景由 `tools/generate-water-caustics.py` 程序生成的原创图 `assets/water-caustics.webp` 提供，不依赖第三方素材
- 液态折射（`glass-renderer.js` / `glass-refraction.js`）：支持的桌面 Chromium 优先用一张共享 WebGL 画布，一次绘制主题壁纸和最多 16 个可见卡片透镜，中心平坦与边缘 RGB 色散共用同一个着色器。滚动、尺寸变化、切换主题或更新内容时会及时重绘。壁纸与各层玻璃采样同一帧，文字保持在独立的 DOM 层。弹窗先按遮罩的模糊半径处理背景，再复用同一个着色器折射，将结果复制到遮罩上方的独立背景层；内部选项、列表和按钮继续叠加折射，不重复叠加模糊或厚重白底。模糊使用小尺寸纹理与限定范围的预过滤/双向处理，关闭弹窗会释放临时纹理。
- 兼容与性能：无 WebGL 或显卡上下文丢失时自动退回单次 SVG 位移；位移图从 512² 降到 256²，避免重复写入未变化的滤镜参数。小屏（≤720px）仅给输入框保留小尺寸折射，其余表面及低性能设备使用透明磨砂降级；支持减少动态效果与减少透明度偏好。各主题共用同一套材质/折射逻辑。
- **弹窗与输入框光学**：设置/词汇收藏/恢复页面/导入选择等弹窗使用“背景先模糊 → 透明玻璃折射 → 清晰文字”的顺序，`LiquidGlass.flush()` 同步完成首帧绘制；文字层不参与模糊或扭曲。弹窗内部列表滚动时同步更新折射，并裁切在内容区，避免列表透镜越过标题；关闭、切换界面或窄屏降级会释放背景画布，无 WebGL 时保留原生折射。所有搜索框（查词、记法、词语对比、API Key、收藏搜索、对比搜索）聚焦时不画边框，整块输入框的折射强度在 240ms 内增强，失焦恢复，快速换焦点可连续反向；输入框使用独立的三次曲线，把最强的放大集中在外缘，向内平滑接上平坦中心，聚焦前后有更明显的凸边差异。位移及色散共同受限，避免折回和内圈分界；卡片、按钮保持各自的原有曲面。不增加白底、光圈或模糊，搜索候选列表仍单独虚化背景。原生后备路径复用位移图只更新强度，小屏只保留输入框的小透镜；动画结束即停止重绘，减少动态效果时直接切换。
- **背景动画**。玻璃界面的水波由两层基于时间的 UV 扰动和微光闪烁组成，跟随显示器刷新率。其他玻璃壁纸空闲时以约 30 帧/秒更新，复用原有壁纸纹理。切换主题后，游光从静态预览逐渐显现。传统界面的水波、极光、蜜桃和深空使用 CSS 漂移图层。减少动态效果时使用静态壁纸，隐藏页面时停止绘制。玻璃界面在小屏、自动性能降级或 WebGL 不可用时保留静态预览。
- 本地纹理：在线页面直接复用 `assets/water-caustics.webp`；直接打开本地 HTML 时，按需加载同一图片的内嵌版本 `assets/water-caustics-data.js`，避免 WebGL 跨源限制，不增加普通页面的阻塞加载。修改水波图片后运行 `python tools/generate-water-texture.py` 重新生成；脚本会同时刷新 `appearance.css` / `glass-renderer.js` 中对水波资产的引用哈希，避免浏览器继续用旧图。

## 使用方式

- **在线使用**：https://jmdonbaba.github.io/cet6-dictionary/
- **本地使用**：直接用浏览器打开 `index.html` 即可使用。

保存页面属于当前浏览器的网站数据。无痕模式、切换浏览器配置、清除网站数据或 Edge 的关闭时清理设置仍可能导致记录不可用，持久存储申请不能阻止用户主动清理。重要页面请使用“导出数据”另存备份；旧版备份不含页面记录。

修改脚本或样式后，提交前运行 `node tools/stamp-assets.cjs`，按文件内容更新 `index.html` 中的资源版本。新页面会请求对应版本，避免线上仍加载缓存里的旧玻璃样式或旧折射脚本；无需清除网站数据。`node tools/stamp-assets.cjs --check` 和自动化测试会检查版本是否同步。

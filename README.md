# CET-6 查词助手

- 结合我自身六级搜词需求，适合六级宝宝体质的搜词器。
- 独立的 CET-6 英语查词工具，从 [Cet6Writing](https://github.com/jmdonbaba/Cet6Writing) 项目中剥离，单独优化，之后再并入。

## 功能

- **AI 查词**：输入单词或短语，调用 DeepSeek API 返回释义、英式与美式音标、词性、变形、学术例句；旧收藏在下次查询时补全双音标，收藏、保存页面和导出均保留两套音标
- **怎么记**：桌面左侧公共工具区生成拆分记忆和词块来源，主卡片保持页面居中；生成不自动收藏，已收藏词需手动点击“收藏”后才补充记法，此时提示“记法已补充到单词收藏”；未收藏词在记法卡片原位自动查词，成功后单词与记法一起收藏并提示“单词与记法已一起收藏”，失败保留记法供重试；记法面的“取消收藏”只移除记法、保留单词收藏（再点收藏提示“记法已补充到单词收藏”），要连同单词一起取消请到“单词释义”面点“取消收藏”；翻面时收藏按钮提前就位，不会翻完才出现
- **拆分记忆**：记法只保留“词块（中文含义） + 词块（中文含义） → 组合含义 → 单词释义”这条公式和每个词块的来源，不再额外生成“这样联想 / 记住这一点”等复述段落；来源行如实说明词块是词根、前缀、后缀，还是联想到某个英文单词（例如 plaus ← 词根：拍手、鼓掌，与 applause 同源），纯联想会明确写出，不把联想当词源；收藏详情和 HTML/Markdown 讲义保留相同格式，旧的联想/提示段落仍可读取
- **释义与记法翻面**：同一张单词卡片可通过“单词释义 / 怎么记”按钮绕中心竖轴翻转，翻转采用平面转动，两面高度差在翻面过程中平滑过渡，卡片下端和收藏按钮都不会卡顿或延后出现；优先复用当前卡片、其他卡片或收藏中的释义，没有时才查询；两面的内容和当前显示面参与刷新及保存页面恢复，系统减少动态效果时直接切换
- **卡片内生成记法**：单词信息行最右侧可直接点击“生成记法”，按当前结果单词生成，在原卡片翻面展示，不新增卡片或自动收藏；生成失败保留原释义，可再次点击重试
- **词语对比**：输入两个词，生成核心区别、使用场景、搭配和例句；手动收藏到同一收藏入口的“词语对比”页签，支持搜索、置顶、删除、打开卡片和讲义导出；交换两个词的顺序不会重复收藏
- **手机工具切换**：公共工具区通过“怎么记 / 词语对比”页签点击或左右滑动切换，结果卡片继续上下阅读；兼容键盘操作和系统减少动态效果设置
- **变形还原**：自动识别过去式、现在分词等变形，显示原形结果
- **多窗口查词**：支持 +/− 按钮添加/删除多个查词窗口，可同时查询多个单词
- **词汇收藏**：收藏感兴趣的词汇，支持置顶、查看详情、删除
- **记法与对比备份**：记法跟随单词收藏及 HTML/Markdown 讲义导出；对比使用独立本地存储，完整数据备份包含两类收藏；旧备份不清空对比收藏，新结果卡片也参与刷新恢复与保存页面
- **定位未收藏卡片**：点击卡片右侧下方的方形双星按钮（上实心、下空心），跳到页面中第一个尚未收藏的查询结果
- **轻量 Q 弹交互**：按钮按压回弹、模式滑块、卡片入场和弹层展开采用统一的轻弹效果，支持系统减少动态效果设置
- **界面设置与主题**：右上角齿轮打开设置面板，可切换「传统界面 / 玻璃质感（开发中）」，并从「极简 / 水波 / 极光 / 蜜桃 / 深空」中选择背景主题。两套界面分别记住各自的主题：传统界面默认「极简」（最初的样子），玻璃质感默认「水波」。选择保存在本地浏览器，刷新或下次打开自动恢复；切换即时生效，支持键盘操作、Esc 关闭与点击遮罩关闭
- **玻璃交互**：鼠标悬停会在当前玻璃表面产生跟随指针的小范围折射变化，点击出现有衰减的果冻回弹；不额外绘制凹陷明暗或圆形阴影。静止时仍保持“边缘鼓、中间平”的材质；交互只改变光学层与装饰层，文字清晰、点击区域固定。支持卡片、内部分层、按钮和弹窗；鼠标停住、移出或回弹结束后自动停止更新，切换界面/关闭效果/失焦会清理交互，减少动态效果或减少透明度时停用此交互。
- **整体折射板**：外层卡片上只叠加一块完整的透明结果板。释义、词形、例句和记忆内容共用这块板的连续曲面，不再逐段设置透镜，也不叠加白色底色或例句边线；学习卡片与收藏详情采用同样规则。共享 GPU 读取外层已经合成的背景，并裁切到自身及祖先的圆角范围；滚动条、高分屏和缩放下使用画布实际边界定位，避免按钮旁多出偏移圆、卡片外多出折射条。按钮保留独立透镜，弹窗与原生降级也使用完整结果板。
- **玻璃按钮与输入框**：所有按钮、滑动胶囊和输入框使用无白色填充的透明底与轻微反光，收藏、删除等状态只保留少量语义染色；原形/原词的文字保持同色，仅滑动胶囊表示选中。折射强度在外缘快速升高，通过平方后的连续平滑曲线向内衰减，扩大大板过渡范围以增强厚边，中心核心保持平坦、不放大；位移变化受限以避免内部折回分界，圆角采用保持方向的二维坐标场。小按钮通过曲面强度归一化（最高 2.6 倍）获得相对更明显的边缘弯折；这不是随尺寸改变材质折射率。主界面的按钮、输入框和胶囊复用共享 GPU 画布，先复制卡片合成背景一次，再按各控件的小矩形裁切绘制，不增加全屏透镜循环。原形/原词选项本身不各自生成透镜。弹窗与原生降级使用独立背景层；输入框用兄弟装饰层承载折射，文字/图标始终清晰。动态按钮、滑动胶囊和刚展开的菜单会自动更新。收藏/删除色彩、禁用与键盘焦点保持可辨认，传统界面保持原样。
- **玻璃质感界面（开发中）**：卡片采用无连续描边的透明玻璃，内容与玻璃层分离（文字不会被折射滤镜扭曲），通过渐变透镜折射带、平坦中心、真实 RGB 采样色散、固定局部反光和柔和投影表现厚度；不同背景主题共用同一套 UI、材质与交互，只替换壁纸，不为深空等主题单独修改卡片和控件样式；背景可选程序生成的浅水焦散（水波，默认）、极光色域、暖色日落或暗色深空；水波主题在玻璃界面由 GPU 着色器逐帧流动（跟随显示器刷新率），其他主题背景保持静止，Q 弹反馈保留在小控件上。系统开启“减少动态效果”时停用动态反馈；不支持背景模糊或开启“减少透明度”时自动降级为清晰卡片，可读性优先
- **收藏打开卡片**：展开收藏后点击“在卡片中打开”，保留收藏夹并定位背景卡片；已打开的单词直接定位
- **刷新恢复卡片**：自动保存卡片顺序、输入、查询模式和结果，在当前标签页刷新时恢复，无需重新查词
- **多标签页恢复**：每个标签页刷新时恢复自己的卡片，新打开的页面保持空白；关闭浏览器或重启电脑前，请使用“保存页面”保留需要的内容
- **保存与恢复页面**：无需命名或下载文件，保存后按时间、卡片数量和单词预览选择记录；覆盖已有内容时先确认，恢复后仍保留记录，可重复恢复，只有手动删除才移除；重启电脑后可在“恢复页面”中找回（需使用同一浏览器、同一页面地址并保留网站本地数据）
- **保存检查与备份**：查询中会提示等待完成，保存页面使用 IndexedDB 严格持久化事务，等待事务提交并校验后才提示成功，避免浏览器被强制结束时丢失刚保存的记录；旧版页面记录自动迁移，并在浏览器支持时申请持久存储保护；底部“导出数据”包含保存页面、收藏和 API Key，“导入数据”可找回页面记录，重复导入不会重复添加，覆盖收藏也会保留已有页面记录
- **共享收藏**：与原 Cet6Writing 项目共享 `localStorage` 中的词汇收藏数据

## 技术栈

- 纯前端 HTML/CSS/JS（无依赖）
- DeepSeek API（deepseek-flash）
- IndexedDB 严格持久化事务保存页面记录；localStorage 保存 API Key 和收藏；sessionStorage 保存当前标签页的刷新快照
- 界面外观（`appearance.css` / `appearance.js`）：界面（`cet6_interface_style`）与背景主题（`cet6_theme_classic` / `cet6_theme_glass`）双维度设置；玻璃质感用低雾度 `backdrop-filter` + SVG 背景折射 + 局部反光实现，不引入 React 或第三方运行时依赖；极光、蜜桃和深空增加共用光带轮廓（`assets/glass-ribbons.svg`，同一 SVG 内嵌为 CSS mask，支持直接打开本地 HTML）；水波背景由 `tools/generate-water-caustics.py` 程序生成的原创图 `assets/water-caustics.webp` 提供，不依赖第三方素材
- 液态折射（`glass-renderer.js` / `glass-refraction.js`）：支持的桌面 Chromium 优先用一张共享 WebGL 画布，一次绘制主题壁纸和最多 16 个可见卡片透镜，中心放大与边缘 RGB 色散共用同一个着色器；只在滚动、尺寸、主题或内容变化时重绘；水波主题例外，由时间 uniform 驱动逐帧流动，其他主题空闲时不循环绘制。折射采样来自壁纸，不捕获或扭曲 DOM 文字。弹窗位于模糊遮罩上方，保留弹窗自身的原生背景捕获和单次 SVG 位移，避免把遮罩下方的透镜错误用于弹窗。
- 兼容与性能：无 WebGL 或显卡上下文丢失时自动退回单次 SVG 位移；位移图从 512² 降到 256²，避免重复写入未变化的滤镜参数。小屏（≤720px）、低性能设备及不支持的浏览器使用透明磨砂降级；支持减少动态效果与减少透明度偏好。各主题共用同一套材质/折射逻辑。
- **弹窗与输入框光学**：设置/词汇收藏/恢复页面等弹窗在 `openModal` 里同步刷新原生折射滤镜（`LiquidGlass.flush()`），首帧就带最终色散，不再先闪一下再变色；弹窗本身改成透明折射玻璃（背景先模糊再被原生位移滤器折射，文字层不参与扭曲）；内部选项、收藏列表（改为圆角卡片）和页面记录也改成半透明玻璃：先对背景做 `backdrop-filter` 模糊保证可读，再叠加被原生 SVG 位移滤器扭曲的高光层形成透明折射（每行独立折射贴图，文字始终在未扭曲层上方）。所有搜索框（查词、API Key、收藏搜索、对比搜索等）聚焦时不再画边框，改用更亮的磨砂玻璃 + 顶部内高光 + 局部模糊提示焦点（文字输入不做位移折射，避免出现横向接缝）；按钮等其他控件的折射保持不变。
- **水波动画**：玻璃界面下的水波由壁纸着色器逐帧流动（`glass-renderer.js`，两层基于时间的 UV 扰动 + 微光闪烁），帧率跟随显示器刷新率（本机 144Hz 实测约 144fps，60Hz 屏幕即 60fps）；传统界面则用一层 `mix-blend-mode: soft-light` 的 CSS 漂移图层（纯合成，不触发布局）。系统开启“减少动态效果”或页面隐藏时水波冻结，其他主题保持完全静止、空闲不重绘。
- 本地纹理：在线页面直接复用 `assets/water-caustics.webp`；直接打开本地 HTML 时，按需加载同一图片的内嵌版本 `assets/water-caustics-data.js`，避免 WebGL 跨源限制，不增加普通页面的阻塞加载。修改水波图片后运行 `python tools/generate-water-texture.py` 重新生成；脚本会同时刷新 `appearance.css` / `glass-renderer.js` 中对水波资产的引用哈希，避免浏览器继续用旧图。

## 与Cet6Writing的关系

- 共享 `cet6_api_key` — API Key 两个项目只需配置一次
- 共享 `cet6_vocab_favorites` — 任一项目中收藏/删除的词汇会自动同步
- 不包含作文生成功能，纯查词+收藏

- **长页面导航**：玻璃模式的置顶/置底滚动与折射绘制在同一帧更新，每一步保留视口重叠，避免大量卡片快速经过时玻璃背景落后。滚轮、触摸、点击或导航键可中断；结束后停止绘制。关闭按钮使用 32×32 的正方形点击区域。

## 使用方式

- **在线使用**：https://jmdonbaba.github.io/cet6-dictionary/
- **本地使用**：直接用浏览器打开 `index.html` 即可使用。

保存页面属于当前浏览器的网站数据。无痕模式、切换浏览器配置、清除网站数据或 Edge 的关闭时清理设置仍可能导致记录不可用，持久存储申请不能阻止用户主动清理。重要页面请使用“导出数据”另存备份；旧版备份不含页面记录。

修改脚本或样式后，提交前运行 `node tools/stamp-assets.cjs`，按文件内容更新 `index.html` 中的资源版本。新页面会请求对应版本，避免线上仍加载缓存里的旧玻璃样式或旧折射脚本；无需清除网站数据。`node tools/stamp-assets.cjs --check` 和自动化测试会检查版本是否同步。

- `node tests/glass-controls.browser.js`：验证按钮/输入框透明底、胶囊选中同色、输入框实际折射、正方形关闭按钮、原生输入文字清晰、降低透明度及清理。

- `node tests/glass-performance.browser.js`：验证空闲时不持续绘制、滚动/鼠标移动不重复重建 SVG、减少透明度降级和 WebGL 上下文丢失后的原生恢复；输出极简/玻璃的帧间隔对照。`GLASS_FORCE_FALLBACK=1 node tests/liquid-glass.browser.js` 可强制检查无 WebGL 路径（PowerShell 用 `$env:GLASS_FORCE_FALLBACK='1'`）。
- `node tools/benchmark-glass.cjs`：隔离浏览器创建 10 张含释义、变形和例句分层的卡片，对比极简/玻璃在空闲、鼠标移动、连续滚动下的帧间隔、慢帧数和主线程耗时，结果写入 `.gstack/glass-perf/latest.json`。2026-11-01 的同机 Edge 1440×900 对照中，旧玻璃滚动 P95 约 139ms，当前透明分层版约 7ms，与极简约 7ms 接近，二者滚动超过 25ms 的慢帧均为 0；这属于该测试环境的帧调度结果，不代表所有设备或浏览器的固定帧率。
